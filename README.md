# GigaMart E-commerce Platform

GigaMart is an e-commerce platform designed to streamline the shopping experience by integrating WhatsApp for inquiries and order finalization. It offers a simple and efficient workflow for both users and sellers.

## Features

- **Product Browsing**
  - Explore products by category with detailed information, images, and pricing.
- **Cart Management**
  - Add products to your cart, modify quantities, or remove items.
- **Checkout Process**
  - Review a detailed summary of selected products before proceeding.
- **WhatsApp Integration**
  - Use Click to Chat to finalize inquiries directly with sellers.
- **Unique Inquiry IDs**
  - Automatically generate IDs for tracking and communication.
- **Order Tracking**
  - Registered users can view order statuses via their account dashboard.
- **Seller Dashboard**
  - Sellers can manage inquiries, update statuses, and convert them into orders.

## User Workflow

1. **Browse Products**: Navigate through categories and add items to the cart.
2. **Checkout**: Review the cart and proceed to checkout.
3. **Provide Details**: Input necessary information if not logged in.
4. **WhatsApp Redirection**: Confirm orders through WhatsApp with a pre-filled message.
5. **Track Orders**: Use the generated Inquiry/Order ID for status updates.

## Seller Workflow

1. Access the secure seller dashboard.
2. Manage inquiries with detailed information, including user details and product requests.
3. Update inquiry statuses:
   - Pending
   - In Negotiation
   - Completed
   - Cancelled
4. Convert successful inquiries into orders with unique IDs.

## Technical Highlights

- **WhatsApp Click to Chat**:
  - Enables users to chat with sellers without saving their number.
  - Uses WhatsApp’s URL scheme for seamless redirection.
- **Email Notifications**:
  - Transactional emails for inquiry confirmations, order updates, and notifications.
- **Mobile Responsiveness**:
  - Fully optimized for mobile devices to enhance the user experience.
